# Your first print from this collection

[← Back to the gallery](../README.md)

Start on the project’s own page. It tells you what the object is, which version to use, and what has actually been checked.

## Choose the right file

| File | What you get | What to do |
|---|---|---|
| `.3mf` | A project or geometry container; contents vary | Open in Bambu Studio, verify printer, nozzle, filament, plate and settings, then inspect the sliced preview. |
| `.stl` | Mesh geometry | Import in millimetres, use the documented orientation, and slice for your printer. |
| `.scad`, `.blend`, `.py` | Editable design or generator source | For inspecting or modifying the design; final geometry is supplied separately where available. |
| `.zip` | A packaged set of project files | Extract it first and read its README. |

**Bambu Studio** is the desktop slicer; **MakerWorld** is the model-sharing platform. Model-specific MakerWorld links will be added after publication. This repository does not upload to your printer or start a print automatically.

## Before you start the printer

Check dimensions against your intended use. Select your actual printer, nozzle, filament and build plate, then inspect the sliced layer view. Confirm that supports, seams, overhangs and small parts make sense. Use the supplied coupon or fit test before a larger assembly when available. Slicer times are estimates; measured print times are labelled as measured.

## Understanding project status

| Label | What it establishes |
|---|---|
| **Prototype / mesh checked** | The digital mesh has been inspected. This does not establish printability, fit, strength or safe load. |
| **CAD checked + sliced** | Geometry and a slicer result have been reviewed. A physical print may still be untested. |
| **Tested by George, as reported** | George has reported a physical test; the project page states what evidence is recorded. |
| **Documented physical test** | Photos, settings and specific observed results are recorded. Reserved for projects with that evidence. |
| **Release pending** | Files or publication await a stated prerequisite. |

For the dragon and pixel shelves, unresolved adhesive mounting on textured paint is part of the status. Do not infer a load rating from a mesh check or the reference drawings.

## Share what you learn

Use a [print report](https://github.com/gdayoub/george-Print-files/issues/new?template=print-report.yml) for a successful make or a problem. Include the project, version, printer, nozzle, material, settings and a photo if possible. Describe untested changes as untested.

Remixing or selling prints depends on each project’s source rights and license. Check its credits before redistributing files or offering prints commercially.
