Prepared through the Windows Bambu Studio 2.8.2.61 interface for a **Bambu P1S, 0.4 mm nozzle, Textured PEI Plate and Generic PLA**. All objects use the black PLA filament entry. Confirm the actual spool mapping when starting a print.

The project contains the complete ten-part Emberwing set and **one Rift pod**, not the five-pod display. Estimated total: **29 hours 14 minutes and 1,235.11 g PLA**, including the slicer's preparation estimates. These are predictions, not measured print results. Have sufficient filament for each job; the whole set exceeds one 1 kg spool.

Per-plate display values are rounded; the total comes from the unrounded metadata. Settings are 0.28 mm layers, 0.20 mm first layer, four wall loops, four top and bottom layers, 15% gyroid and supports off. Parts retain the supplied rear-face-down orientation. All eight plate previews were inspected, with additional first-layer and intermediate-layer checks on representative parts. Bambu reported no slicing errors, and every plate's metadata reports no object outside the build area. Both 3MF archives passed CRC checks; the sliced archive contains eight G-code files.

Start one plate at a time after clearing the bed. For more Rift pods, use the editable project and prepare a pod-only plate so repeated jobs do not also produce extra crests. The three unused filament entries inherited in the project are not consumed by these toolpaths.

This remains a physically untested prototype. Successful slicing does not establish strength, fit or reliable adhesive mounting on textured paint. Follow the [mounting and first-print notes](PRINTING.md) before installation.
