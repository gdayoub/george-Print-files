# Design credits and file status

## Source

The supplied `gengar_miska_9cm.3mf` names **tom3Dmodel** as designer, **Gengar pokemon Bowl** as title, and **Standard Digital File License** as its license. Its model identifier is `US605db9232b8769`. The exact original listing URL has not been verified.

## George's adaptation

This project changes the bowl into a deep can holder, raises the character, adds finger recesses, and develops separate glue-in eyes and grin for faster single-color printing. George reports testing his version. The original sculpted character mesh was retained and modified.

## Public files

The source license restricts redistribution of modified model files. Permission has not been confirmed, so this prepared showcase does not include public STL/3MF downloads. Attribution does not replace permission. This repository does not relicense the supplied model.
